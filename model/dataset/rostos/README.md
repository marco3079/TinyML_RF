# Imagens de rosto

Coloque nesta pasta as imagens JPG, JPEG ou PNG usadas no treinamento.

Para cada imagem, crie um arquivo TXT com o mesmo nome no formato YOLO:

```text
0 centro_x centro_y largura altura
```

Exemplo:

```text
pessoa01.jpg
pessoa01.txt
```

As quatro coordenadas devem estar normalizadas entre 0 e 1.
